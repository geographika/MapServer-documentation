1. Overview
===========

OGC Features API support was added in :ref:`rfc134` and documented at :ref:`ogcapi`.

The modular nature of OGC API means many parts of the OGC API are already implemented and are shared with the OGC Maps API
such as landing pages, conformance, and collections. 
Links:


https://github.com/opengeospatial/ogcapi-maps - GitHub repository
